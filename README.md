# HUSHBYTE

"Keep it lowkey."

A tiny Python project for turning your messages into coded text.

Type it.
Encode it.
Keep it lowkey.

## What can it do?

- Encode your message
- Decode it back
- Simple terminal UI
- No extra libraries
- Beginner-friendly

## How it works

```text
Your message
     ↓
   Encode
     ↓
Coded message
     ↓
   Decode
     ↓
Your message
```

## Run it

```bash
python main.py
```

Then choose:

```text
[1] Encode Message
[2] Decode Message
[3] Exit
```

## Example

```text
hello hushbyte
        ↓
aGVsbG8gaHVzaGJ5dGU=
```

Decode it and...

```text
hello hushbyte
```

easy. no drama.

## Built with

- Python
- Base64

## Tiny note

HUSHBYTE uses "Base64 encoding", not encryption.

So yeah... it's coded, but "not actually secret-secret".
